## 💡 Learning Philosophy

1. **Depth > Speed**: Never rush. True competence takes time.
2. **Understanding > Memorization**: Focus on *why* things work, not just *how* to type them.
3. **Difficult Problems > Easy Examples**: Challenge builds capability.
4. **Actual Code > Watching**: Writing code is the only way to learn coding.
5. **Documentation > Chat History**: Everything learned must be permanently recorded.
